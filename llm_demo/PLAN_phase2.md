# 第二阶段计划：大模型读结构时，到底读到了什么？

师姐的建议（2026-10-29）：先用小模型多找几条一致的规律，最好围绕一个统一方向，方便写论文；之后再用大模型验证，大小模型结论一致就更好写。

## 已有的规律（第一阶段，见 RESULTS.md）

**规律 1：平均池化的冻结 LLM 特征 ≈ 代码文本的词频（再加一层随机的非线性混合）。**
小样本好，是因为词频是很强的简化描述；样本多有上限，是因为词频分不清"同样的词放在不同位置"。三个搜索空间（NB201、TransNAS、NB101）、6 个模型版本都成立。

## 要找的新规律

### 规律 2（核心）：上限由"写法"决定，不由模型决定

同一个结构换几种写法，预言：**每种写法下，LLM 特征的表现 ≈ 这种写法的词频特征的表现**（小样本和大样本都是）。

| 写法 | 例子（NB201） | 词频里有什么 | 预言 |
|---|---|---|---|
| code（已有） | `x2 = self.conv3x3(x0) + self.zero(x1)` | 操作计数 | 有上限 |
| edges 边列表 | `edge 0->2: conv3x3` | 操作计数（位置写了，但被拆成单独的词） | 有上限，和 code 差不多 |
| sorted 只列操作 | `operations: conv3x3 conv3x3 identity ...` | 操作计数（位置被删掉） | 和 code 一样 |
| nl 自然语言 | `Node 2 adds conv3x3 of node 0 and zero of node 1.` | 操作计数 | 有上限 |
| posword 位置词 | `cell: tiger river ...`（每条边、每种操作各用一个专门的英文单词） | 完整的 one-hot | **没有上限**，样本多时接近 one-hot |

论文主图：横轴是词频特征的 τ，纵轴是 LLM 特征的 τ，每个点是"写法 × 搜索空间 × 样本数"。点落在对角线附近，就说明规律成立。

实用结论：不换模型，只换写法，就能去掉上限。

### 规律 3：模型大小、预训练程度不改变规律 2

Pythia 70M / 160M / 410M / 1B，每个都比较随机初始化和训练完成两个版本。预期：每个模型的点都落在同一条对角线上。之后用大模型验证同一张图。

### 规律 4：取特征的方式决定保留多少位置信息

比较最后一层和中间层，"所有词取平均"和"只取最后一个词"。已经看到"分行平均"能突破上限，这一条把它系统化。

### 规律 5（应用）：对"找最好的结构"有什么影响

N@10 的偏差是不是也来自"词频相同的结构分不开"；用一个简单的搜索过程验证。

## 顺序和时间

1. 规律 2：先算每种写法的词频（几分钟），再用两个 Pythia（第 0 步、第 143000 步）提特征。每个空间最多 5000 个结构，一晚上跑完；第二天评估。
2. 规律 3：下载 Pythia 70M / 160M / 1B（第 0 步和第 143000 步），在规律 2 最有代表性的几种写法上跑。
3. 规律 4、5 视时间再定。
