## 高优先级：count_ceiling 并非 Kendall tau 的数学上限
位置 explain.py:136–141。按相同特征分组，使用全体真实标签的组均值预测，再计算 tau。均值最优对应平方误差，不保证排序指标最优。
反例：A=[0,1,100]，B=[2,3,4]。按均值排序 tau=-0.2581988897，反向排序 tau=+0.2581988897。同一特征约束下存在更高 tau，故上限声明不成立。
另外结果使用被评估样本的标签，属于描述性的 oracle 参考，不能直接作为泛化性能估计。
影响：step2、step3、step7 等所有调用 count_ceiling 的上限解释。建议先改定义为“组均值 oracle 参考”，若要严格上界需另行推导并处理并列。

## 高优先级：第四页参考线的特征与总体不一致
make_summary_fig.py:19–22 硬编码 0.629/0.509/0.462。TransNAS 七任务均值可复核；NB101 0.462 来自 423624 全量，图曲线来自 5000 子集，子集纯计数参考为 0.445。
NB101 词频还有连线信息，不能用纯操作计数约束词频或 LLM。0.625 是另外六维特征的全量组均值 oracle，也不能直接替代为 LLM 或词频上界。
LLM 上下文隐藏状态平均不等于输入词频；有位置信息时超出纯计数参考本身不是代码错误。

## 第六页符号：没有证据表明灰色数据丢失
step3_formats.py:68–70,206,218–220：颜色表示格式，红色=posword；形状表示空间，圆=NB201、方=TransNAS、三角=NB101。红方是合法组合。灰色只出现在手工图例句柄中，不是应当出现的数据系列。

## 中优先级：相关系数不等于性能一致
复算随机 Pythia/训练 Pythia/Qwen 全部点 r=0.927753/0.882752/0.863004；MAE=0.037390/0.052882/0.053874。固定 n=1000 的 r=0.830/0.653/0.540。混合训练规模会包含共同学习曲线趋势，不能单凭 pooled r 证明格式决定模型上限。
posword、TransNAS 场景分类、n=1000：bow=0.774，随机Pythia=0.623，训练Pythia=0.609，Qwen=0.579。显著偏差不可被总平均掩盖。125点中75点来自TransNAS（三任务），因此也不是三个搜索空间等权。

## 中优先级：可复现性与缓存风险
run_formats.py:73,88 仅凭文件存在跳过，不核对文本、池、模型版本、数组行数。--limit 若未指定隔离目录，会把少量特征保存在完整 pool.npy 旁，后续正式运行跳过。属于可触发代码风险，未证实污染当前结果。
step3_formats.py:101,129：断点补算整组后 drop_duplicates 默认保留旧值；旧结果优先且没有输入指纹，改变配置或数据后可能混合旧缓存。当前六份最终CSV未发现重复主键或NaN tau，但这不能验证缓存来源。
step2.py:97–111 NB201/TransNAS加载全量标签而非显式使用pool.npy，依赖池为全量原顺序，缺乏断言；当前需进一步核验原始池及所有LLM数组对齐。

## 已验证特征
formats 结构池 NB201=5000、TransNAS=4096、NB101=5000，均无重复。各 bow 数组行数匹配池且值有限。
NB201 code/edges/nl/sorted 各204种，posword5000种；TransNAS前四种各84种，posword4096种；NB101 code1749/edges3416/nl2336/sorted44/posword5000种。因此“前四种格式都只包含操作计数”在NB101上不成立。posword唯一性只说明该池没有特征碰撞，不保证有限样本可学到tau=1。
