## 绿线的结论
PPT原句“The LLM curve stays on the green ceiling line”没有得到原算法支持。水平绿线不是LLM学习曲线渐近极限，只是按操作计数组内真实均值预测得到的描述性tau。
未为贴曲线修改常数，也未宣称算出了真正LLM上界。图保留两种明确不同的用途：
1. python .\llm_demo\make_summary_fig.py：复现水平oracle参考诊断图，图例明确NOT an LLM limit。
2. python .\llm_demo\make_summary_fig.py --counts-baseline：实际训练的操作计数RF学习曲线，绿色虚线不是上界。
两者均导出各绘图点和共同种子数CSV；跨方法采用共同seed/相同任务，防止不同种子数量改变比较口径。
